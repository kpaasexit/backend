개요

Exit Gateway API 문서입니다.

HTTP 동사

본 REST API에서 사용하는 HTTP 동사(verbs)는 가능한 한 표준 HTTP와 REST 규약을 따릅니다.

동사 용례

GET

리소스를 가져올 때 사용

POST

새 리소스를 만들 때 사용

PUT

기존 리소스를 수정할 때 사용

PATCH

기존 리소스의 일부를 수정할 때 사용

DELETE

기존 리소스를 삭제할 때 사용

HTTP 상태 코드

본 REST API에서 사용하는 HTTP 상태 코드는 가능한 한 표준 HTTP와 REST 규약을 따릅니다.

상태 코드 용례

200 OK

요청을 성공적으로 처리함

201 Created

새 리소스를 성공적으로 생성함

204 No Content

기존 리소스를 성공적으로 수정함

400 Bad Request

잘못된 요청을 보낸 경우

401 Unauthorized

인증되지 않은 요청

403 Forbidden

권한이 없는 요청

404 Not Found

요청한 리소스가 없음

500 Internal Server Error

서버 에러

인증 API

OAuth2 소셜 로그인

개요

Exit 애플리케이션은 카카오와 네이버 OAuth2 소셜 로그인을 지원합니다. 로그인 성공 시 JWT 액세스 토큰과 리프레시 토큰이 발급됩니다.

카카오 로그인

로그인 시작

사용자를 카카오 로그인 페이지로 리다이렉트합니다.

Request
GET /oauth2/authorization/kakao HTTP/1.1
Host: api.exit.com
Response
HTTP/1.1 302 Found
Location: https://kauth.kakao.com/oauth/authorize?client_id={client_id}&redirect_uri={redirect_uri}&response_type=code&state={state}

로그인 콜백 (자동 처리)

카카오 인증 완료 후 자동으로 처리되는 엔드포인트입니다. (사용자가 직접 호출하지 않음)

Request
GET /login/oauth2/code/kakao?code={authorization_code}&state={state} HTTP/1.1
Host: api.exit.com

로그인 성공 리다이렉트

인증 성공 시 클라이언트 애플리케이션으로 JWT 토큰과 함께 리다이렉트됩니다.

Response
HTTP/1.1 302 Found
Location: http://localhost:3000/oauth2/redirect?token={access_token}&refresh={refresh_token}
Table 1. Query Parameters
Parameter Type Description

token

String

JWT 액세스 토큰 (URL 인코딩됨)

refresh

String

JWT 리프레시 토큰 (URL 인코딩됨)

로그인 실패 리다이렉트

인증 실패 시 에러 파라미터와 함께 리다이렉트됩니다.

Response
HTTP/1.1 302 Found
Location: http://localhost:3000/oauth2/redirect?error=login_failed

네이버 로그인

네이버 로그인은 카카오와 동일한 플로우를 따르며, 엔드포인트만 다릅니다.

로그인 시작

Request
GET /oauth2/authorization/naver HTTP/1.1
Host: api.exit.com
Response
HTTP/1.1 302 Found
Location: https://nid.naver.com/oauth2.0/authorize?client_id={client_id}&redirect_uri={redirect_uri}&response_type=code&state={state}

로그인 콜백 (자동 처리)

Request
GET /login/oauth2/code/naver?code={authorization_code}&state={state} HTTP/1.1
Host: api.exit.com

성공/실패 리다이렉트는 카카오와 동일합니다.
